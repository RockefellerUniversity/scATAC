# Single-cell ATAC-seq

<br>

This course introduces the analysis of single-cell ATAC-seq (scATAC-seq) data in R using the [Signac](https://stuartlab.org/signac/) and [Seurat](https://satijalab.org/seurat/) packages. scATAC-seq measures chromatin accessibility in thousands of individual cells, letting us map regulatory regions and identify cell types and states from the epigenome rather than the transcriptome.

The course runs as a one-day workshop split into four sessions:

| Session | Time | Topic |
|---|---|---|
| 1 | 9:30–11:00 | **Foundations** — chromatin accessibility, the costs and benefits of single-cell resolution, Cell Ranger ATAC outputs, fragment files and importing data into Signac/Seurat |
| | 11:00–11:15 | *Break* |
| 2 | 11:15–12:45 | **QC and Preprocessing** — scATAC-specific QC metrics, filtering thresholds, TF-IDF normalization and peak-set selection |
| | 12:45–1:45 | *Lunch* |
| 3 | 1:45–3:15 | **Dimensionality Reduction and Clustering** — LSI, UMAP, graph-based clustering, gene activity scores and label transfer from scRNA-seq |
| | 3:15–3:30 | *Break* |
| 4 | 3:30–4:30 | **Differential Accessibility and Visualization** — marker-based and pseudobulk differential accessibility, and coverage plots of regions of interest |

Some familiarity with R and with single-cell RNA-seq analysis in Seurat is assumed.

Course material and exercises are available to view as rendered HTML at https://rockefelleruniversity.github.io/scATAC/.
All material is available to download under GPL v2 license.
